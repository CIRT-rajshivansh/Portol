# Shivansh Raj — Blue Team Operations Portfolio

Static, responsive SOC portfolio. No build tools, packages, external fonts, images or APIs.

## Deploy to GitHub Pages
1. Create a public GitHub repository (for example `blue-team-portfolio`).
2. Upload `index.html`, `style.css` and `script.js` to its root.
3. Open repository **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Your site will appear at `https://YOUR-USERNAME.github.io/blue-team-portfolio/` after GitHub finishes deploying.

## Before sharing with recruiters
- Replace GitHub/LinkedIn placeholders in `index.html` with your real profile links. Do not link to a guessed username.
- Verify each certification and update the status and link in `script.js`.
- Add evidence URLs and real redacted screenshots for each case. The current case-dialog evidence controls are explicitly non-clickable placeholders.
- Add confirmed CTF results and community contributions only when available.
- Verify the 40+ room claim and add individual platform profile URLs.
- Review project wording against your actual completed lab work. Never publish real credentials, unredacted personal data or third-party sensitive logs.
- The hero console is illustrative, not live telemetry.

## Customize
Edit the `cases` and `certifications` arrays in `script.js`, and your introduction and contact links in `index.html`. All styling lives in `style.css`.

## Update your EXISTING GitHub Pages repository
Open your current repository, choose **Add file → Upload files**, and upload the five website files (`index.html`, `style.css`, `script.js`, `shivansh-portrait.jpg`, and optionally `README.md`) into the repository root. Commit the changes to the same branch already configured under Settings → Pages. Replace existing files rather than making a new repository. Your published URL stays the same.
